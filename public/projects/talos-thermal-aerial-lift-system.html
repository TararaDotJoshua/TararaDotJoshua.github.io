TALOS - Thermal Aerial Lift System.

Project manager for the MUAV group at Florida Tech ARES, building a thermal-imaging UAS for Mars-relevant research.

01The Problem

Stand up a thermal-imaging UAS program that produces usable data, not just airframes.

The group needed a repeatable platform and a test plan tied to mission objectives, with subsystem teams coordinated rather than working independently.

02My Approach

Decompose the program into sprints and schedule subsystems in parallel.

Broke the program into subsystem requirements and managed work through Scrum sprints tracked in Jira. Scheduled payload integration against mission windows. Wrote requirement traceability so subsystems could progress at the same time.

03The Action

Coordinated subsystem deliverables and ran the integration plan.

Ran sprint planning and backlog grooming in Jira. Tracked requirements, scheduled test events, and drove integration between thermal payload and airframe teams.

ScrumJiraProgram managementRequirementsTest scheduling
04The Result

Group operating against a structured plan.

Documented integration plan and sprint-based schedule replaced ad-hoc builds. Jira backlog gave subsystem leads visibility into cross-team dependencies.
