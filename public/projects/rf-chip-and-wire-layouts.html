RF Design · 2023 – 2024

RF Chip-and-Wire Layouts.

10+ chip-and-wire RF layouts and a shared component block library for high-frequency defense microelectronics at Mercury Systems.

01The Problem

Layouts were one-offs across two DoW programs.

Each board started from scratch. Reviews relitigated basic geometry, and nothing carried forward to the next layout.

02My Approach

Capture recurring blocks in a shared library and write a layout standard.

Catalogued footprints, clearances, and ground returns for the blocks that kept reappearing in AutoCAD. Wrote a layout convention so reviewers could check against the standard rather than redo it. Managed all layout revisions and releases through SolidWorks PDM.

03The Action

Released 10+ chip-and-wire layouts and grew the library in parallel.

Delivered layouts across both DoW programs in AutoCAD. Checked all files in and out through SolidWorks PDM. Folded review feedback back into the standard so the library improved with each board.

AutoCADSolidWorks PDMChip-and-wireDoW programLibrary
04The Result

Layout iteration time dropped, reviews focused on new content.

Library blocks were reused on follow-on boards. Qualification reviews stopped restating geometry that was already standardized. PDM provided a full revision history for every layout released.
