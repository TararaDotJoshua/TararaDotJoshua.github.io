UAS · 2024 – present

Aeroversa Systems.

Co-founder. Modular drone platform for industrial inspection. One airframe, mission-swappable payloads.

01The Problem

Operators with multiple inspection missions end up running multiple fleets.

Inspection drones are priced and specced for single missions. There is room for one airframe that swaps mission hardware.

02My Approach

Build the airframe around a payload bay.

Standardized bay interface plus a common avionics interface across payloads. Mission specialization lives in the bay.

03The Action

Owning structure, payload bay design, and avionics integration.

Working from CAD through prototype hardware as a co-founder.

ModularInspectionSystems eng.Startup
04The Result

One airframe covers multiple missions through bay swaps.

Concept holds up against the multi-fleet pattern operators currently maintain.
