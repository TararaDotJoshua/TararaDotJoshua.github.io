# Joshua Tarara Portfolio

Personal mechanical-engineering portfolio built with React, Vite, Framer Motion, and Three.js.

The home page includes an interactive 26:1 dual cycloidal-drive model and links to static project case studies in `public/projects/`. The public site deploys to GitHub Pages from `main`.

## Local development

```sh
pnpm install
pnpm dev
```

Build and lint before deploying:

```sh
pnpm build
pnpm lint
```
